# 固定版式契约 v1

源自已确认的双段精批样式。参考资产只保留几何／颜色与合成示例，不包含个人简历。

包内 `assets/example-preview.png` 是合成测试材料的版式预览，不是模型实跑。原文长短不同会改变留白，不得为了填满页面补造经历。

- 画布 1600 × 1060 pt，白底、灰色细分隔线。左右不等宽。
- 左侧：x=32，顶部128，最大620×884；完整 PDF 页等比置入，矢量保留，不用抽取文字重建；两处细红框与外侧编号对应右侧段落。
- 右侧：x=700，宽868；两段起点119与567。原文摘录仍来自 PDF，不是重新排版的引文。
- 每段：编号与标题、原岗位、原文摘录、选择性黑红改写、通常3–4条有标题的补充记录／深层追问。已答题显示用户已确认摘录，未确认与跳过项标明状态；允许无剩余问题，不凑数。默认改写19.5pt、行距27；追问14.2pt、行距20.5；不要靠无限缩字塞内容。
- 保留内容黑色，新增／改写红色，明确删除原句可加红色删除线。【】内一律红色。标题／说明灰黑，避免满屏红字。
- 默认使用 PyMuPDF 内置 Droid Sans Fallback 字体并嵌入子集，跨系统无需商业字体。`--font` 可指定有许可的 TTF/OTF/TTC；换字体后必须重新渲染，字体指标会稍变。
- 在语义断点换行，保留原文字串；支持 `break_after` 指定原句中的唯一短语，不让单位或「同期」孤立断行。
- 多页 PDF：每个源页按顺序出现；同页超过两段继续分页并重复完整原页。单页两个重点放不下时各占一张展示页；单个重点仍过长则明确失败，要求缩短问题／拆分焦点，不裁字、不改写已确认正文。
- 没有重点的源页原样附入，避免为凑版式制造建议。
- 扫描图 PDF 保留图像，不声称矢量文字；可读文字不足时停止要求可搜索 PDF 或获准的本地 OCR。正文不会由脚本重新 OCR 后排版。

`assets/layout.json` 是脚本的几何／颜色来源。修改模板时同步版本与测试，确认每页 PNG 无裁切、重叠、断字和乱码。
