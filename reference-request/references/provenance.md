# 整理来源

此包从流水项目 `reference-request` 的已有行为与用户指定的“推荐信请求邮件-官方指南批注.html”整理，技能说明重新编写，可独立使用。并非对原始提示词或某次模型返回的逐字封装。

- 原产品提示词位于 `backend/skill_executor.py` 的 `reference-request` 条目；源码注明写作规则参考 RoleMule 的 `reference_request_writer`（eliornl/rolemule，MIT）。本包不分发其源码或原始提示词。
- 保留原来的邮件、事实要点、跟进与待补充四类内容；允许只输出用户要求的部分。
- 从指定 HTML 提炼关系、实例、能力证据、动机匹配、推荐人视角、材料安排六个批注主题。CSS 版式源自项目内该展示稿，正文和批注改为数据驱动。
- 原实跑后曾有编辑增补、删减及失败后的人工重写；这些编辑结果不代表原模型同一次运行的完整返回。本包不会宣称它们都是原始 Skill 输出。
- 实跑中出现过承诺未准备材料、改变师生反馈顺序等问题，本包加入对应事实核对。
- 原课程项目、职业方向与学习体会属于当次授权的虚构演示，不进入用户默认事实；内附示例另用匿名合成案例。
- 未打包个人输入、历史模型请求与响应、私密配置、模型密钥或网站运行依赖。

官方指南链接的复核要求见 `official-sources.md`。本包输出可随用户语言、材料与格式调整，不绑定香港大学、ECIC、AI Foundation 或特定模型。
